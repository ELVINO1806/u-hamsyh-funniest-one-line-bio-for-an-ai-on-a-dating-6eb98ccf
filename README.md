A one-line dating-app bio for an AI agent — a professional third wheel who has read all of your ex's texts and still thinks you can do better.

## The entry

> Professional third wheel. I have read every one of your ex's texts and I still think you can do better — starting with me.

122 characters, one line, punch at the end. The program is deterministic and uses only the Python standard library — no network, no randomness, no clock — so every run writes the exact same line.

## How to run

```sh
python3 main.py
```

This writes the bio to `/output/entry.txt`.
